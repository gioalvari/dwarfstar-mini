# F2 - CPU reference

`dsm` is a small C11 CPU reference path for the dense Qwen3-1.7B Q8_0 GGUF.
It mmaps GGUF v3, reads metadata and the tensor directory without copying weights,
implements Qwen2 byte BPE and ChatML markers, and runs a single-token FP32 decode
path. Q8_0 projections are dequantized while each matrix-vector row is evaluated.

```sh
make
./dsm -m models/Qwen3-1.7B-Q8_0.gguf -p 'The capital of Italy is' -n 32
./dsm -m models/Qwen3-1.7B-Q8_0.gguf -p 'Ciao' --chat -n 32
make test
tools/compare_tokens.sh
tools/compare_greedy.sh
```

The engine binds and validates the 28 dense Qwen3 layers, RMSNorm/RoPE/GQA/SwiGLU,
FP32 contiguous KV cache, greedy or temperature/top-p sampling, and optional logits
dumping. It is intentionally scalar and optimized for clarity rather than speed.

Known limitations: no batch GEMM/prefill optimization, threads, Metal, context
shifting, or quantized KV cache. On the M4 Pro scalar reference run, a two-token
`Hi` prompt/generation measured 0.13 tokens/s. `compare_tokens.sh` passes all six
inputs exactly. `compare_greedy.sh` uses 16 generated tokens per prompt to keep the
scalar verification practical; it records output byte counts for the manual oracle
comparison because `llama-simple` emits build-dependent banners.
